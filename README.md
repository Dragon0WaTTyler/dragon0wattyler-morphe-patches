# Dragon0WaTTyler's Morphe Patches

An independent Morphe patch source based on the Morphe Patches project. It currently carries the optional **PocketTube-style Subscription Groups** patch and the upstream patches from its pinned Morphe base. It is not an official Morphe or PocketTube release.

<a href="https://morphe.software/add-source?github=Dragon0WaTTyler/dragon0wattyler-morphe-patches"><img src=".github/assets/add-to-morphe.svg" alt="Add to Morphe Manager" height="48"></a>

## Install or update in Morphe Manager

1. Open the add-source link above, or add `Dragon0WaTTyler/dragon0wattyler-morphe-patches` under Patch sources.
2. Enable **Pre-release** for this source to receive `dev` branch builds.
3. Select this source for YouTube when patching. This bundle contains the Morphe patches from its pinned base plus the optional Subscription Groups patch. Avoid selecting another source for the same app, since independently built sources can conflict.
4. When this repository publishes an update, use the Update badge in Morphe Manager and repatch YouTube.

The `dev` branch publishes prereleases through the official Morphe template workflow. Changes merged to `main` publish stable releases. Release bundles and metadata are generated by GitHub Actions.

## Subscription Groups status

V6.1 is an experimental candidate. It includes PocketTube JSON import, local group storage, group feeds with automatic channel coverage, caching, filters, playback routing, and an experimental native-menu binding bridge. Full native menu parity has **not** been verified on stock YouTube 21.30.216 or a target Android device. The bridge may fall back to the limited Android menu when a valid native binding is unavailable.

See [verification](docs/subscription-groups/VERIFICATION.md), [known limitations](docs/subscription-groups/KNOWN_LIMITATIONS.md), [native-menu investigation](docs/subscription-groups/NATIVE_MENU_INVESTIGATION.md), and the [Android checklist](docs/subscription-groups/ANDROID_CHECKLIST.md). RSS/channel sources expose only finite recent-upload windows; full YouTube upload history and PocketTube live synchronization are not implemented.

## Build

Use JDK 21, Android SDK 36 / Build Tools 36, then run:

```bash
./gradlew :patches:test :extensions:youtube:testDebugUnitTest :extensions:music:testDebugUnitTest checkStringResources
./gradlew :patches:buildAndroid
```

The `.mpp` bundle is written to `patches/build/libs/`. The verified V6.1 candidate used pinned Morphe build dependency sources; its exact build details and limitations are recorded in the verification documents.
