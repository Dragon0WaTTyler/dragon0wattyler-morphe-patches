# Dragon0WaTTyler's Morphe Patches

An independent, growing collection of **Morphe patches for Android apps**, focused on customization, useful new features, and a better user experience across different apps.

This is an independent community patch source, not an official Morphe project or an official release from the developers of the supported apps. The supported apps and versions depend on the available patch releases.

## Releases and development

- `dev`: ongoing development and pre-release builds.
- `main`: stable releases when changes are merged.
- Release files and patch metadata are generated by the existing GitHub Actions workflow.
- Build locally with `./gradlew buildAndroid`. The `.mpp` bundle is created in `patches/build/libs/`.

See the [Morphe documentation](https://github.com/MorpheApp/morphe-documentation) for more details.
