# Multi-app repository policy

The existing `Dragon0WaTTyler/dragon0wattyler-morphe-patches` repository remains the shared Morphe source and release stream for its supported apps. Blackmagic Camera is maintained as its own application section alongside YouTube, YouTube Music, Reddit, and PocketTube.

The development release workflow, versioned `.mpp` assets, `patches-list.json`, and `patches-bundle.json` continue to serve the existing add-source URL:

`https://morphe.software/add-source?github=Dragon0WaTTyler/dragon0wattyler-morphe-patches`

Do not create a separate Blackmagic Camera repository or move its patches out of this source unless the repository owner explicitly changes this direction. The historical per-app repository migration proposal is superseded by this policy.
