# PocketTube Groups V8 Android checklist

Run against the user's target Samsung S23 Ultra and YouTube 21.30.216 before calling the layout device-verified.

- Open Subscriptions and confirm the toolbar-to-content gap is gone or record its measured remaining height.
- Confirm the selector is one compact button, displays `All groups` or the current `Group: …`, and opens a vertical native menu.
- Confirm the vertical menu scrolls with a large group library and remains usable with long group names and icons.
- Select All groups and several groups; verify the selected group persists across tab changes and app restart according to Remember group/default settings.
- Verify content filters and their remembered/default behavior after changing groups.
- Create, rename, delete, pin, reorder, export, and import groups from the existing management entry points.
- Check group overflow for a video with a live native command and an RSS-only video without one; verify the latter reports/uses the documented custom fallback.
- Verify playback, long-press actions, scrolling, rotations, search, fullscreen, and leaving/re-entering Subscriptions.
