# groups.6.1 compatibility limitations

**Full native-menu integration is not verified or universally available.** This is a test candidate, not evidence that every ⋮ now opens the stock menu. The exact21.30.216 APK is not available here and no device is connected. Read NATIVE_MENU_INVESTIGATION.md for the source-level evidence and exact missing context.

Native reuse requires one exact, live native UI-thread binding for the same video, a recognized native command schema, unchanged command bytes, the same active activity/account generation, a visible attached group sender and age≤60s. Startup Home bindings before host initialization and unbound/public-source-only videos cannot be reused. Account/token/visitor/page/incognito changes conservatively invalidate capabilities. No captured commands/account data are persisted. The existing shared flyout dependency still needs to match the target. Unsupported bridge resolution retains the small fallback.

The route has been exercised with production parsers/registry and native-shaped protobuf/Java test doubles, representative Robolectric views and synthetic DEX. Those checks do not execute the target native renderer, confirm native UI presentation or perform signed-in actions. Async native presentation/anchor behavior, all stock item dispatchers, casting/queue, feedback, account switching and entitlement-controlled downloads need device testing. Native UI may still reject a custom anchor/context. No Premium restriction is bypassed, and no unsupported stock action is manually added. The fallback preserves Play/Open channel/Android Share/local watched controls plus existing V6 capability-gated native adapters when ready; these optional native adapters also retain their V6 runtime limits.

Local watched/unwatched is separate: long-press ⋮. The native menu is not modified to inject it. The fallback remains visibly the small Android PopupMenu; it is not a stock-look imitation.

All existing V6 source limits remain: RSS automatically attempts every unique channel but exposes only a finite recent-upload window (typically15/channel), with no full upload history or global arbitrary video cap. Public enrichment has finite windows and can be missing/stale/blocked. Source thumbnail metadata can overstate actual JPEG dimensions. Local watched state covers only this installation's completed/manual IDs, not account-wide history or cross-device sync. Its default is OFF; conservative regular-playback completion requires90% unique intervals and≥30s active observation; Shorts/live/incognito/unobserved contexts require manual marking. Per-group filters remain in schema2 state; no re-import/migration is needed. Full PocketTube synchronization is not implemented.

Physical scrolling/playback, ART verification, native Home menu equivalence, Samsung cutout/rotation/RTL and all existing selected Morphe features remain target runtime gates. LICENSE/NOTICE and exact pinned build sources accompany the candidate. V1–V6 artifacts remain untouched for rollback.
