# groups.5 implementation plan

Continue the preserved groups.4 source, targeting stock YouTube 21.30.216/API29+.

1. Keep V4 channel coverage/session/caching/import/store/navigation behavior. Build a separate V5 output and audit V1–V4 checksums.
2. Add immutable video presentation metadata (duration, explicit type/live status, avatar URL), independently cached per channel. Public channel Videos/Shorts/Live pages expose authoritative tab membership, durations and channel avatar; retain Atom publication timestamps. Parse bounded initial JSON, validate channel identity and trusted image hosts. No duration-based Shorts guesses. Podcast membership requires explicit YouTube podcast metadata; unknown stays unknown.
3. Fetch enrichment asynchronously with bounded concurrency, shared single-flight cache and cancellation of obsolete queued work. Show Atom results immediately. Reuse channel metadata across group/filter changes and disk restarts; avoid per-video avatar lookups. Use a bounded shared image loader and per-binding identity checks.
4. Retain native filter behavior for All Groups. For custom groups, replace the native filter row with compact matching All/Today/Videos/Shorts/Live/Podcasts chips, filtering local cached metadata. Mark native filter text using the existing scoped Litho text hook and identify its mounted page-local Litho view, preserving/restoring the original view without changing unrelated tabs. Remove the old scope workaround. Unknown classifications are excluded from specific type filters and explained in optional Details/limitations.
5. Hide the subscribed-channel carousel through existing exact Litho component identifiers and existing tablet/landscape hook boundaries, scoped to Subscriptions/integration. Preserve normal video avatars, toolbar/insets, other tabs and selector.
6. Group selector labels contain complete names without counts, even with legacy saved count preferences. Keep membership data and management counts.
7. Circular channel images with initials on missing/failed metadata; thumbnail bottom-right badges use exact duration or explicit live/upcoming status, no invented zero duration. Preserve click routing and 16:9 geometry.
8. Add focused parser/cache/filter/local-midnight/label/duration/image-rebinding/scoped-chrome tests. Run complete existing JVM suites/string checks and buildAndroid. Audit MPP runtime entries, license/provenance and source archive.
9. Deliver bundle, source archive, actual test results, five-fix changelog, runtime checklist and limitations. Actual APK matching, exact YouTube hierarchy and S23 runtime responsiveness remain pending unless a target APK/device is available; compilation/Robolectric are not runtime proof.

Investigation evidence: V4 GroupVideo/Atom omit avatar,duration,type. GroupFeedView uses TextView initials and no overlay. SubscriptionsPage appends saved counts and a scope workaround. LayoutComponentsFilter already names subscriptions_channel_bar/subscriptions_chip_bar; hide/general fingerprints cover tablet constructor/landscape width. Existing text-component and Litho relayout hooks provide typed component path and mounted drawable identity. Public channel page probe is in work/groups5/research (not redistributed user data). No PocketTube API or private application storage is accessed.
