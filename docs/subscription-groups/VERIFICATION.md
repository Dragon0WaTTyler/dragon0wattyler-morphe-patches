## Native integration limits and current evidence

Source inspection confirms V6's limited menu is an Android PopupMenu. FeedVideoActionsPatch opens an already-bound native Litho button; FlyoutPatch receives a native command plus sender/endpoint/logger context; AskFlyoutMenuPatch exposes original Elements command/tap bridges and native sheet/popup row dispatch. Queue hooks operate on existing native models. GroupVideo's public model supplies none of the full native account/feedback binding context.

V6.1 captures only actual UI-thread native menu handlers in an established activity, derives a native command field at patch time, validates one exact menu/ID and reuses the original command/context/handler. No native action list, feedback endpoint or entitlement bypass is invented. A scoped native-entry check supplies exact identity to existing Morphe actions without title heuristics. Original native menu models/opaque commands are unchanged. Local watched actions stay on long-press ⋮.
