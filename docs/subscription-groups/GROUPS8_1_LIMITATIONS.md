# PocketTube Groups V8.1 limitations

- The user-provided Samsung screenshots confirm the visible top gap and fallback menu in V8. The row-collapse regression now removes the exact fingerprinted Subscriptions channel-carousel container from its parent and restores its original position on exit. Android fixture tests verify the measured content top moves up by the row height. No Samsung device or YouTube 21.30.216 APK is connected here, so final visual confirmation of the screenshot and normal status-bar/toolbar spacing remains a device check.
- Native menu reuse now also has access to commands captured before the first Groups host is established. It can open the real YouTube menu only when the same video ID has a still-live, same-account native Elements handler captured while Groups is enabled. The original handler is weakly held and expires after 60 seconds; the complete command digest and video identity are rechecked before dispatch.
- RSS-only group videos, IDs absent from a currently retained native card, commands older than 60 seconds, recycled handlers, account changes, incognito, unsupported patch layouts, or invalid/mixed command payloads continue to use the custom menu. Public feed metadata still cannot construct YouTube's account-specific renderer, endpoint tokens, or action context.
- Native menu row actions, download eligibility, casting, account mutations, and menu geometry from the custom anchor still need the target-device check. The local watched/unwatched actions remain available by long-pressing the group-card overflow control.
